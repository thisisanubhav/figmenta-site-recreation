Italian locale propagation

Italian corporate links use locale-free division roots, which resolve to /en.

Shared URL generation preserves the active locale and opens the matching division /it route.

Regional contact email targets

All three visible regional addresses target mailto:info@figmenta.com.

The visible address and its mailto: destination are generated from the same office value.

Vacancy application context

An expanded vacancy has no role-specific Apply action; only the generic HR email is available.

Every vacancy includes an Apply CTA whose email subject and body preserve title and role reference.
